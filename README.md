# 🛍️ TechStore

### Modern Full-Stack E-Commerce Website

TechStore is a responsive e-commerce web application built with React, Node.js, Express.js, MongoDB and Tailwind CSS.

## ✨ Features

- 👤 User Registration & Login
- 🔐 JWT Authentication
- 🛒 Shopping Cart
- 📦 Checkout & Order Placement
- 🍃 MongoDB Database
- 📱 Responsive Design
- 🚀 Vercel Deployment

## 🛠️ Tech Stack

React.js • Vite • Tailwind CSS • Node.js • Express.js • MongoDB • JWT
